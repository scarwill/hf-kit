# Published Netlight long-video scripts

One file per video: `<publish date>-<slug>.txt`, first line `# <title> · <length> · <date>`. Lines starting with `#` are section names.
- `net-shorts` cuts Shorts from these (the one moment that works alone).
- `../scriptcheck.py` compares a new script with these (REUSED = a 5-word phrase that is also in 2+ of them).
Add the final script here after every video (ask before pushing).
