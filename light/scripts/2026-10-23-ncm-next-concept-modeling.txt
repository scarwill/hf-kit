So, how do you write a sentence without starting at the first word? Stick with me because by the end you'll see exactly how it works.
# How a normal language model writes
First, how does a normal language model write? It breaks text into small pieces called tokens. A token is a word or part of a word. Then, it predicts one token, then the next, left to right. And once a token is written, it stays written. It never goes back to fix it. For a sudoku, that's a disaster. One wrong number early and the whole board falls apart.
# How diffusion models write
Diffusion models write all the words together over many rounds, but they work on the full sentence in every round. And with fewer rounds, quality drops fast.
# Rough first: the Stanford paper
Now, think about how you write an essay. You start with a rough idea, then an outline, then the details. A team from the Hazy Research Lab at Stanford built a model that writes exactly like that. Their October 2026 paper calls it coarse to fine text generation. Rough first, sharp later. Let's follow one real sentence from the paper, a German sentence that says small and medium-sized companies remain vulnerable to hacking and surveillance. The job is to translate it.
# Two stages: vectors and a codebook
NCM works in two stages. First, it learns a new way to describe text. Then, it learns to write in it. Stage one, turning a sentence into levels. Every token becomes a list of 384 numbers, a vector. But the model doesn't keep those exact numbers. It keeps a code book, a list of 4,096 learned patterns. Every vector gets swapped for the number of its closest pattern. Like a paint shop. You don't describe your exact wall color. You point at the closest shade on the chart and say its number. That number is a code.
# Paying in cash: residual levels
Now, here's the twist. One round of codes is never exact. Something is always left over. So, the model does it again on just the leftover. Think of paying 287 in cash. A 200 note, 87 left, so a 50, then a 20, a 10, a five, and a two. Each step pays only what's still missing. NCM does exactly that in levels, and each level has its own code book, and the levels grow. Level one has just one code, one code for the entire sentence. Level two has four, then eight, then 14. By level 11, there are 64, one for every token. So the first level is the gist. The last level is the fine print.
# What a "concept" means here
To be clear, that's all the paper means by a concept. Not a human idea like dog or love. Just what those early rough levels carry. But why would that single first code hold anything useful? Because during training, about half the time, the finer levels are simply cut off, and the model still has to rebuild the sentence from what's left. So the early levels are forced to carry the most important part. Then a decoder adds all the levels together and turns them back into words.
# Stage 2: learning to write
Stage two, learning to write. The code maker is frozen. A separate transformer, about 120 million parameters, learns to predict the codes. And here's the key. It looks at everything built so far and predicts every code in the next level at once. One level, one step. So this whole translation takes 11 steps. A normal model needs 64, one per token. # Back to Sudoku
So remember that Sudoku. NCM sketches the whole board first and every new level can fix earlier mistakes. A left to right model can't. Once a number is down, it stays down. On hard puzzles, NCM solved 86% in 12 steps. The best diffusion model reached 81 using 16.
# What does speed cost?
Quick question for you. If a model gets 20 times faster, what does it give up? According to the paper, on news sentences, NCM beat the strongest diffusion model on a standard quality score while running 21 times faster. On news summaries, it matched it and ran 31 times faster. Now, let's be honest, because this isn't magic. Here's what it gives up. On translation, NCM scored 22.6 on a score called BLEU. The best diffusion model scored 24.8. And the models are small. The biggest tested has 725 million parameters and the paper calls its scaling results preliminary. So no, this is not the end of normal language models. Not yet.
